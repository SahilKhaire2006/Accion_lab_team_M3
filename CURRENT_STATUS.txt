ERROR EXPLANATION
================================================================================

The error you saw:

  "error: Microsoft Visual C++ 14.0 or greater is required"

This happens because the 'av' (PyAV) package needs to be compiled from source
code on Windows, which requires Visual Studio C++ Build Tools.

SOLUTIONS:
1. Use install_fix.bat (tries to get precompiled version)
2. Install requirements-simple.txt (flexible versions)
3. Install Visual Studio Build Tools (if above fails)

Full details in: INSTALLATION_GUIDE.md
